Características

Todo lo que necesitas, en un solo lugar

Diseñado para ser robusto, seguro y fácil de usar directamente desde la línea de comandos de tu dispositivo.

ADB Inalámbrico Nativo

Conecta tu dispositivo vía WiFi usando el protocolo de emparejamiento de Android 11+ o el método clásico de puertos.

Gestión de Apps y Archivos

Lista, instala, desinstala y extrae (pull/push) aplicaciones y archivos del sistema de forma segura y validada.

Backup y Restauración

Extrae los APKs de tus aplicaciones instaladas o realiza backups completos del sistema con manifiestos de integridad.

Logs y Diagnóstico

Accede a logcat, dmesg, información de batería, almacenamiento y realiza capturas de pantalla remotas al instante.

Perfiles por Fabricante

Configuraciones optimizadas y listas de paquetes protegidos para Samsung (One UI), Google Pixel y Xiaomi (MIUI/HyperOS).

Arquitectura de Plugins

Extiende las capacidades de la herramienta creando tus propios módulos en Python sin modificar el núcleo del sistema.

Preguntas Frecuentes

Resolvemos tus dudas

¿Necesito root para usar la herramienta?

No. cell_phone_modifier está diseñado para funcionar exclusivamente con ADB, por lo que no requiere root ni modificaciones al sistema. Esto lo hace más seguro y compatible con la garantía de tu dispositivo.

¿Qué versiones de Android son compatibles?

Es compatible con Android 8.0 (Oreo) en adelante. El emparejamiento inalámbrico nativo requiere Android 11+, pero el método clásico de puertos funciona desde Android 8.

¿Funciona en dispositivos Samsung, Xiaomi y Pixel?

Sí. Incluye perfiles específicos optimizados para Samsung (One UI), Google Pixel (Stock) y Xiaomi (MIUI/HyperOS), con listas de paquetes protegidos y configuraciones adaptadas.

¿Cómo puedo contribuir al proyecto?

El proyecto es open source bajo licencia MIT. Puedes contribuir reportando bugs, creando nuevos módulos (plugins en Python), mejorando la documentación o enviando pull requests en GitHub.

¿Es seguro usar la herramienta en mi dispositivo principal?

Sí, siempre que uses los módulos de forma responsable. La herramienta incluye validaciones de seguridad, manifiestos de integridad en los backups y listas de paquetes protegidos para evitar daños accidentales.

Instalación en 30 segundos

Asegúrate de tener Termux instalado desde F-Droid y ejecutar estos comandos.

pkg update && pkg install python android-tools git
git clone https://github.com/JAVIER10733/cell-phone-modifier.git
cd cell-phone-modifier && chmod +x setup.sh && ./setup.sh
